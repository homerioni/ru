# Ассеты: «Ясен Квасен: Раздевалка»

Все картинки генерируются **заранее**, до разработки логики, и кладутся в `public/game/kvas/`.
В рантайме ничего не генерируется.

## 1. Стиль

- Пиксель-арт в духе 16-битных игр, вид спереди с лёгким сверху. Стилистика чиби: голова крупная, примерно треть роста.
- Палитра ограниченная, около 32 цветов, общая для всех ассетов. Без градиентов, без сглаживания, контур в 1px тёмного цвета.
- Освещение тусклое, раздевалочное: зеленовато-серая плитка, ржавые шкафчики, деревянная скамейка.
- Цвета формы клуба берутся из логотипа клуба. **Если цвета неочевидны — спросить владельца сайта** и записать их в `manifest.json` (`kitColors`).
- Банка «Ясен Квасен»: жёлто-зелёная, на ней крупная надпись «ЯК» и колосок. Узнаваема даже в 12×20 px.

## 2. Технические требования

- Базовое разрешение сцены **320×180**. Все размеры ниже даны в пикселях этой сетки.
- Формат PNG с прозрачностью (кроме фона). Без полупрозрачных пикселей: альфа только 0 или 255.
- Спрайт-листы: кадры **горизонтально в один ряд**, ячейки одинакового размера, без отступов между ними.
- Генераторы картинок не рисуют точную пиксельную сетку, поэтому пайплайн такой:
  1. Генерировать в крупном размере (кратном итоговому, например ×8) на однотонном фоне `#FF00FF`.
  2. Уменьшить до целевого размера методом **nearest neighbor**.
  3. Привести к общей палитре (квантизация) и заменить `#FF00FF` на прозрачность.
  4. Склеить кадры в спрайт-лист.

  Для обработки можно разово использовать скрипт на Python (Pillow) или ImageMagick, положив его в `scripts/kvas-assets/`. В зависимости проекта ничего не добавлять.
- После обработки проверить: кадры одного листа совпадают по размеру и опорным точкам (ноги и скамейка не «прыгают» между кадрами, кроме случаев, где прыжок задуман).

## 3. Слоистая схема персонажа

Чтобы не генерировать сотни картинок, персонаж собирается из слоёв. **Тело общее** для всех игроков, **голова своя** у каждого.

```
[ голова игрока (своя) ]   ← крепится к точке шеи текущего кадра тела
[ банка в руке ]           ← крепится к точке руки текущего кадра тела
[ тело: стадия пуза × кадр ]
[ скамейка / диван ]
```

### 3.1 Тело — `public/game/kvas/body/belly-{0..5}.png`

- 6 файлов, по одному на стадию пуза из GDD. Ячейка **96×96**, 5 кадров, итоговый лист 480×96.
- Кадры по порядку: `0 сидит`, `1 подносит банку`, `2 пьёт (запрокинул голову)`, `3 отрыжка (откинулся назад)`, `4 довольный (руки на пузе)`.
- Игрок в форме клуба (футболка, шорты, гетры, бутсы) сидит на скамейке. Номер на спине не нужен: номер на груди рисуется в коде поверх, мелким пиксельным шрифтом.
- Стадии 4–5: форма порвана, торчит пупок, на стадии 5 игрок почти круглый.
- Для каждого кадра каждой стадии задаются опорные точки `neck` и `hand` (x, y внутри ячейки). Их записывают в `manifest.json` (раздел 6).

### 3.2 Голова игрока — `public/game/kvas/players/{playerId}/head.png`

- Генерируется **по фото игрока** (поле `photo` из `getPlayers`, это URL картинки). Узнаваемость важнее красоты: причёска, борода, цвет волос, очки — всё, что выделяет человека.
- Ячейка **64×64**, 4 кадра, лист 256×64: `0 обычное лицо (лёгкая ухмылка)`, `1 глоток (глаза зажмурены, щёки надуты)`, `2 отрыжка (рот открыт, глаза навыкате)`, `3 довольное (блаженная улыбка, румянец)`.
- Голова в анфас, точка шеи в нижнем центре ячейки (32, 62).
- Генерировать для всех игроков с `type === 'player'` и непустым `photo`. Если фото нет, голову не генерировать: в игре будет заглушка.

### 3.3 Заглушка головы — `public/game/kvas/players/_default/head.png`

Те же 4 кадра. Безликая голова в балаклаве цвета клуба, на лбу место под номер (номер рисуется кодом). Подпись в UI: «Тайный легионер».

## 4. Сцена

### 4.1 Фон — `public/game/kvas/room/base.png` (320×180, без прозрачности)

Раздевалка: плитка на стенах, кафельный пол, ряд ржавых шкафчиков слева, деревянная скамейка по центру, дверь справа (закрытая), в темноте. Свет только из щели под дверью. Скамейка является частью фона: игрок рисуется поверх неё.

### 4.2 Слои улучшений — `public/game/kvas/room/upgrade-{1..9}.png` (320×180, прозрачные)

Каждый слой рисуется поверх фона в тех же координатах, порядок как в GDD. Если у улучшения есть анимация, слой делается спрайт-листом 2–3 кадра по горизонтали (то есть 640×180 или 960×180).

| `upgrade-1.png` | лампочка на проводе по центру потолка + слой «освещённости» (комната становится светлее) | 2 (качается) |
| `upgrade-2.png` | гирлянда вдоль верха стены | 2 (мигает) |
| `upgrade-3.png` | плакат «Ясен Квасен» на стене за скамейкой | 1 |
| `upgrade-4.png` | магнитофон «Весна» на полке + нотки | 2 |
| `upgrade-5.png` | колонка на месте магнитофона (магнитофон скрывается в коде) | 2 (подпрыгивает) |

### 4.3 Свет — `public/game/kvas/room/dark.png`

Полупрозрачная тёмная виньетка 320×180, исключение из правила об альфе (допустима альфа 0–200 ступенями по 40). Показывается, пока не куплено улучшение 1. Во время мега-отрыжки показывается на 2 кадра.

## 6. `public/game/kvas/manifest.json`

Единый источник правды для кода: какие головы есть, где опорные точки, где слоты.

```json
{
  "kitColors": { "shirt": "#??????", "shorts": "#??????", "socks": "#??????" },
  "players": [12, 15, 31],
  "body": {
    "cell": [96, 96],
    "frames": 5,
    "anchors": {
      "0": [{ "neck": [48, 30], "hand": [70, 60] }, "... по одному объекту на кадр"],
      "1": ["..."]
    }
  },
  "playerPosition": [112, 70],
  "slots": {
    "floor":  [[20, 160], [34, 164], "... 24 точки"],
    "bench":  [[90, 118], "... 6 точек"],
    "shelf":  [[12, 40], "... 10 точек"]
  },
  "pilePosition": [220, 60],
  "pigeonOnPile": [[0, 0], [256, 104], [252, 88], [248, 70], [244, 60]],
  "coachPosition": [270, 70],
  "cleanerPosition": [200, 84]
}
```

- `players` — id игроков, для которых сгенерирована голова. Для остальных используется `_default`.
- Координаты слотов подбираются вручную по фону: банки не должны перекрывать игрока и дверь (дверь нужна для тренера).
- `pigeonOnPile[stage]` — точка вершины горы для каждой стадии.

## 7. Промпты для генерации

Общий стиль-префикс (добавлять к каждому промпту):

```
16-bit pixel art, limited 32-color palette, 1px dark outline, no anti-aliasing,
no gradients, chibi proportions, front view, flat solid #FF00FF background,
humorous, absurd, gritty amateur football locker room vibe
```

| Ассет | Промпт (после префикса) |
|---|---|
| Фон | `dark shabby football locker room interior, green-grey tiled walls, cracked tile floor, row of rusty lockers on the left, wooden bench in the center, closed door on the right with light under it, empty, no people, wide 16:9` |
| Тело, стадия N | `football player body without head sitting on a bench, club kit {kitColors}, sprite sheet 5 frames in a row: sitting, raising a beer can, drinking with head tilted back, burping leaning back, satisfied with hands on belly; belly size: {описание стадии из GDD}` |
| Голова игрока | `chibi head portrait of this person (reference photo attached), recognizable hairstyle and facial features, sprite sheet 4 frames in a row: smirk, sipping with puffed cheeks and closed eyes, burping with open mouth and bulging eyes, blissful smile with blush` |
| Заглушка | `chibi head in a balaclava in club colors, blank forehead area, same 4 expressions` |
| Банка | `small yellow-green beer can labeled "ЯК" with a wheat ear, sprite sheet: closed, opening with foam splash, open, empty standing, empty lying on side, crushed` |
| Гора | `pile of empty yellow-green beer cans, 4 sizes in a row: small heap, knee-high, waist-high, huge pile to the ceiling with a small club flag on top` |
| Тренер | `angry old football coach with big mustache, tracksuit and whistle, peeking through a door: only eye and mustache visible / staring / yelling with whistle` |
| Тётя Валя | `grumpy old cleaning lady with headscarf, apron and a mop: standing / swinging mop / grumbling` |
| Голубь | `tiny grey city pigeon sitting, 2 frames: normal, head turned` |
| Улучшения | по одному промпту на строку таблицы 4.2, с припиской `isolated object, same perspective as the locker room background` |

Головы генерировать пачкой, но проверять каждую вручную: если игрока не узнать, перегенерировать. Лучше пять попыток, чем голова «не того».
