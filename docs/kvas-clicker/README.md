# «Ясен Квасен: Раздевалка» — ТЗ для ИИ-разработчика

Абсурдный пиксельный 2D-кликер на одной отдельной странице сайта Речичане United.
Выбираешь любого игрока клуба — он сидит на скамейке в футбольной раздевалке и пьёт
пиво «Ясен Квасен». Один клик — один глоток. Пустые банки остаются в комнате, пузо
растёт, раздевалка прокачивается. Игра на один вечер (30–60 минут до финала), без
глубокой проработки.

## Документы (читать по порядку)

1. [GDD.md](./GDD.md) — геймдизайн: механики, прокачка, события, юмор, таблица баланса.
2. [ASSETS.md](./ASSETS.md) — стиль, список спрайтов, размеры, кадры, промпты для генерации, нейминг.
3. [TECH.md](./TECH.md) — интеграция в проект, архитектура, состояние, анимации, сохранение.

## Главные принципы

- **Просто.** Не добавлять механик сверх GDD. Если хочется что-то добавить — не надо.
- **Абсурдно и с юмором.** Тексты короткие, стереотипные, по-дворовому смешные.
- **Дёргано.** Никаких плавных переходов и твинов: всё меняется кадрами (`steps()`), предметы
  появляются мгновенно. Банка не падает — она просто уже лежит на полу.
- **Пиксели.** Базовое разрешение сцены 320×180, масштаб только целым числом, `image-rendering: pixelated`.
- **Без новых зависимостей и без бэкенда.** DOM + CSS + `localStorage`.
- Все числа баланса — в одном файле `balance.ts` (значения берутся из GDD).

## Чеклист задач (по порядку)

- [ ] 1. Сгенерировать ассеты по [ASSETS.md](./ASSETS.md): сначала общие (фон, тело, банки, пропсы), потом головы игроков. Собрать `public/game/kvas/manifest.json`.
- [ ] 2. Страница `/game`, пункт меню, экран выбора игрока.
- [ ] 3. Сцена и клик: открыть банку → глотки → пустая банка мгновенно появляется в слоте.
- [ ] 4. HUD: глотки, банки, Квасики, звание. Стадии пуза. Сохранение в `localStorage`.
- [ ] 5. Отрыжка (обычная и мега) + облачка с фразами + тряска.
- [ ] 6. Магазин навыков и магазин раздевалки.
- [ ] 7. Мини-события (тренер, тётя Валя, голубь), звания, финальный экран.
- [ ] 8. Проверка на ширине телефона и прогон баланса (бот-симуляция доходит до финала за 25–40 минут, живая сессия с магазином и событиями занимает 30–60).

## Definition of Done

- Страница `/game` открывается из меню и на телефоне занимает весь экран: комната на всю высоту, тапы, магазин снизу.
- Можно выбрать любого игрока из состава (`type === 'player'`); у игрока без сгенерированной головы — заглушка с номером.
- Прогресс каждого игрока сохраняется отдельно и переживает перезагрузку.
- Все механики из GDD работают, числа совпадают с таблицей баланса.
- `npm run lint` и `npm run build` проходят.
